# 补齐基础类型、条件与循环

本批继续用户要求的基础学习顺序，不把第一批 5 章当成完整基础课程。

- 新增 3 章 × 12 种语言 = 36 个中英实现：基础类型、条件分支、循环与跳转。
- 基础目录现在按语法、变量、常量、基础类型、操作符、条件、循环、函数排列；新增章节有继续阅读关联。
- 总计 8 个基础章 / 96 个基础实现；全部对照文档 28 篇 / 204 个实现。旧 21 个习语 / 87 个实现和学习、收藏、语言选择 ID 不变。
- 不将静态/动态类型、缺失值、条件真值转换或迭代区间解释成所有语言一样。Go 没有独立 while、Ruby 使用 next、Rust/Swift 可选类型等差别按章节说明。
- 逐条一手资料记录见 `docs/foundations2-source-review.md`，仅核查相关正文，不宣称通读完整官方手册；原创示例未执行，不冒充在线可运行 demo。

## 验收范围
沿用 Astro 静态页面 + React 局部交互，无数据库、运行服务、新依赖或费用。保留先前 46 个浏览器项目用例，基础全覆盖用例扩大到 8 章，新增章节串联与语言选择保持用例，共 48 个项目用例。所有实际测试结果以此次提交日志为准，配置不等于通过。

云浏览器验收中英文、深浅色、桌面与窄屏及语言/学习状态操作；窄屏窗口不是原生 iPhone Safari 实机。最终发布需核对远端 main、CI、Pages 和线上 manifest 精确 SHA。

后续仍有集合、字符串操作、对象模型、更多文件/网络任务等内容待扩充，不把本轮称为所有语言文档全部完成。
