# Astro v2 发布验收

## 范围

用户明确批准在 dot 云电脑分阶段迁移，并批准直接 main 与既有 GitHub Pages 发布。本轮没有修改内容快照、没有在线执行服务、数据库、新费用或凭证变化。原 scratch 在恢复时已不存在，按已批准语义重建后重新验证；不把先前记录当作本轮结果。

生产改为 Astro 静态生成 + React 局部交互：21习语、87实现、12语言，38个HTML页面；代码构建期高亮，目录只带摘要，全文代码索引首次搜索时加载。保留旧路由、收藏、语言选择与两个storage键、明暗主题、筛选排序、复制和搜索命中说明。示例输出明确为静态资料，不冒充执行结果。

根 npm ci 安装根和v2锁定依赖；build/validate/pre-deploy已接实际dist，Pages沿用原部署工作流但不再以首页覆盖404。静态详情是200，未知地址为独立404。build-manifest.json记录版本、发布SHA、base和静态内容数量。

## 限制与维护

未独立核验全部既有知识内容、未拿到外部handbook源仓库、未测试真实iOS Safari和低端设备性能。缺少实现不等于语言不支持；语言版本标为资料记录版本。页面水合前正文可读，交互需JavaScript。无速度提升百分比承诺。

AGENTS引用的用户Mac外部账号规范在云端不可访问，没有读取或声称读取。依据同文档“用户明确要求优先”及当前明确云端/仓库/发布授权，只使用naijoug/elsewise已授权连接和既有Pages流程，不扩权限或凭证。

发布完成还需核对远端确切SHA、对应Actions成功、线上manifest与真实页面交互；仅提交不算交付。线上结果由维护会话记录并与manifest交叉确认。
