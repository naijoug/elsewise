# 语言特性地图：内容与验收契约

新增权威内容是本仓库 `v2/src/data/features.json`；不是对外部 tech-cards-handbook 的迁移，也不覆盖旧生成快照 `src/data/idioms.json`。旧习语沿用原同步流程，关联通过稳定 idiom ID 建立。

首批 16 个概念、60 个语言对照条目：继承、行为多态、泛型、闭包分别审阅 12 种已有语言，再各选一个特色机制。并非完整阅读全部手册。`feature-source-coverage.json` 记录实际查看的官方章节、适用版本基线和活文档边界；C++ 使用 WG21 工作草案源及注明身份的 HTML 转录，不冒称正式 ISO 出版文本。

## 可测试判定规则
- 通用：本目录 12 种语言均有经核查条目，比较同一抽象概念，不承诺相同语义。
- 部分共有：原生机制只覆盖部分语言；明确记录其他语言的惯用替代或不适用。没有条目只能表示未收录。
- 语言特色：选择一门语言的代表性机制深入讲解，绝不等于全球唯一；范围说明必填。
- 原生机制、惯用替代、不适用此机制、尚未收录分别记录；Go/Rust 没有类继承不推出不支持多态。
- 每条有版本、中文解释、具体来源章节、核查日期。代码是说明片段，不是实际运行结果。
- 关联指理解关系，不声明等价或历史影响。外键、重复语言、空来源、通用覆盖在构建/单测失败。

## 交互与数据边界
静态生成 `/feature/:id/`，客户端只接收摘要，无全部示例代码或高亮语法包。入口 `/features/` 支持概念文本/标签、语言和学习状态交集筛选；语言页、已有习语详情双向引导。复用多语言比较、收藏、Get、主题与移动布局。新 Get/收藏键使用 `feature:` 命名空间，旧习语状态不改写。收藏页同时呈现两类内容。

后续逐批扩展：类型系统（代数数据类型/约束/型变）、异步与并发、模块与包、资源管理、元编程、设计模式。每批先核具体章节及版本，再补实现和跨概念关系，不按缺失内容推断“不支持”。
